# 回忆记录锚定「一次地点到访」，地点为独立实体

一条回忆记录对应**一次地点到访**，不是一整次旅行一条，也不是每张照片一条。地点（名称、坐标、POI id、类型）作为**独立实体**存储，记录通过地点 id 关联；同一家店多次到访自动归并到同一地点，其综合评分与到访次数由记录汇总派生。

## Considered Options

- **每次到访自带一份地点信息（否决）**：地图上同一家店出现多个 marker，无法表达"这家店我们去过 N 次"，平均分无处挂靠。
- **一整次旅行一条（否决）**：媒体过多、多个地点混在一条里，无法逐点在地图打卡。

## Consequences

- 地点归并依赖搜索选点返回的 POI id；纯手输名称无法归并。
- 地图上永远是"一店一 marker"，marker 展示平均分与到访次数。
- 类型（餐厅/景点/住宿/其他）挂在地点上，首打卡时选定，后续到访自动继承。
