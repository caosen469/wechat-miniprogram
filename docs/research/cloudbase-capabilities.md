# 微信云开发（CloudBase）能力与计费调研

## 1. 核心能力概述

### 1.1 云数据库
- **类型**：文档型数据库（类似 MongoDB）
- **特点**：
  - 支持免部署运维和可视化管理
  - 支持数据读写、数据库事务、自动备份回档等功能
  - 支持在小程序端和云函数中调用
  - 稳定可靠，适合小程序业务场景
- **限制**：
  - 单次出包大小：16M
  - 数据库容量有配额限制（免费版 2GB/月）

### 1.2 云存储
- **特点**：
  - 云端文件存储服务，自带 CDN 加速
  - 支持前端直接上传和下载操作
  - 支持任意数量和形式的非结构化数据存储
  - 高可用、高稳定、强安全
- **用途**：适合存储图片、视频、音频等媒体文件
- **限制**：
  - 单个文件大小：建议不超过 500MB，实际可支持更大文件但可能存在性能问题
  - 不支持 mov 格式视频（线上环境仅支持 mp4）

### 1.3 云函数
- **特点**：
  - 在云端运行的代码，微信私有协议天然鉴权
  - 无需管理服务器，直接编写业务逻辑
  - 与微信登录鉴权无缝整合
  - 云函数调用时自动传入小程序端用户的 openid，开发者无需校验 openid 的正确性
- **限制**：
  - 单次运行内存：256MB
  - 云函数数量：50个（免费版）
  - 数据字段建议临界值：256KB，超过建议使用 CDN 标记

### 1.4 微信授权登录
- **核心标识**：
  - **OpenID**：用户在特定小程序下的唯一标识
  - **UnionID**：用户在同一微信开放平台账号下所有应用的唯一标识（需绑定微信开放平台）
  - **session_key**：会话密钥，用于数据加密
- **获取方式**：
  - 调用 `auth.code2Session` 接口，换取用户唯一标识 OpenID
  - 云函数调用时自动注入小程序端用户的 openid
- **特点**：无需额外配置，开箱即用，与云开发深度整合

### 2.4 针对 4-6 人的月成本估算

**假设场景**：
- 5 个家庭成员
- 每人每天上传 5 张照片（平均 2MB/张）
- 每人每天上传 1 个视频（50MB）

**计算过程**：
1. **每日存储增量**：
   - 照片：5人 × 5张 × 2MB = 50MB
   - 视频：5人 × 1个 × 50MB = 250MB
   - 合计：300MB/天

2. **月存储增量**：
   - 300MB × 30 天 = 9GB/月

3. **CDN 流量估算**：
   - 假设每个文件被查看 3 次
   - 每日流量：300MB × 3 = 900MB
   - 月流量：900MB × 30 = 27GB

4. **数据库操作**：
   - 假设每个文件对应 1 次写操作
   - 每日写操作：5人 × 6个文件 = 30 次
   - 月写操作：30 × 30 = 900 次（远低于免费额度的 1万次/天）

5. **云函数调用**：
   - 每个文件上传调用 1 次
   - 每日调用：5人 × 6个文件 = 30 次
   - 月调用：30 × 30 = 900 次（远低于免费额度的 40万 GB·s）

**成本分析**：
- **免费额度**：5GB 存储 + 5GB CDN 流量
- **超出部分**：
  - 存储：9GB - 5GB = 4GB 超出
  - CDN 流量：27GB - 5GB = 22GB 超出
- **计费估算**：
  - 超出存储费用：约 4GB × (69元/100GB) ≈ 2.76 元
  - 超出 CDN 流量费用：约 22GB × (按资源点计费，约 0.1 元/GB) ≈ 2.2 元
  - 合计：约 5-10 元/月

**结论**：
- **个人版（19.9 元/月）** 完全足够应对 4-6 人的家庭使用场景
- 实际使用可能仍在免费额度内，或仅需支付少量超额费用
- 建议先用免费额度测试，根据实际使用情况决定是否升级套餐

## 3. 媒体上传能力与限制

### 3.1 wx.chooseMedia API 限制

**主要参数**：
- `count`：最多可以选择的文件数量（通常为 9）
- `mediaType`：支持的媒体类型（`image` 或 `video`）
- `maxDuration`：视频最大时长限制（单位：秒）
- `sizeType`：数组类型，用于控制文件大小/压缩类型

**返回参数**：
- `tempFilePath`：临时文件路径
- `size`：文件大小
- `width`/`height`：图片或视频的宽高
- `duration`：视频的时间长度
- `thumbTempFilePath`：视频缩略图临时文件路径
- `fileType`：文件类型（image/video）

### 3.2 具体限制

**视频格式限制**：
- 线上环境只支持 mp4 格式
- 不支持 mov 格式（尽管开发者工具可以选择多种格式）

**视频大小限制**：
- 官方没有明确的硬性限制
- 社区反馈建议限制在 500MB 以内
- 超过 500MB 可能出现选择卡住或不显示的问题

**视频时长限制**：
- 可通过 `maxDuration` 参数自定义限制
- 常见设置为 30 秒、60 秒等

**图片限制**：
- 支持常见的图片格式（jpg、png 等）
- 支持压缩选择（`sizeType` 参数）

### 3.3 上传方式对比

**直传云存储**（推荐）：
- **特点**：
  - 前端直接调用 `wx.cloud.uploadFile` 上传到云存储
  - 无需经过云函数中转
  - 利用云存储自带的 CDN 加速
- **优势**：
  - 减少云函数调用次数
  - 避免云函数的数据大小限制
  - 上传速度快，用户体验好
- **限制**：
  - 需要在小程序端配置云存储权限

**云函数中转**：
- **特点**：
  - 先上传到云函数，再由云函数上传到云存储
- **劣势**：
  - 云函数对数据大小有限制（建议 256KB 以内）
  - 增加云函数调用次数和成本
  - 上传速度较慢
- **适用场景**：
  - 需要对上传文件进行预处理
  - 需要进行复杂的权限控制

### 3.4 上传能力总结

**推荐方案**：
1. 使用 `wx.chooseMedia` 选择媒体文件
2. 使用 `wx.cloud.uploadFile` 直传云存储
3. 将文件信息（fileID、大小、类型等）保存到数据库

**技术要点**：
- 合理设置 `maxDuration` 参数限制视频时长
- 对大文件进行前端压缩或提示用户
- 使用上传进度接口提供用户反馈
- 考虑断点续传功能（针对大文件）

## 4. 登录鉴权与家庭成员管理

### 4.1 OpenID 获取机制

**自动获取**：
- 云函数调用时，微信云开发自动在 `wx-server-sdk` 中注入用户的 openid
- 无需开发者手动校验 openid 的正确性
- 开箱即用，无需额外配置

**手动获取**：
- 调用 `wx.cloud.callFunction` 触发云函数
- 云函数中通过 `event.userInfo` 或云开发 SDK 获取 openid

**代码示例**（云函数）：
```javascript
const cloud = require('wx-server-sdk')
cloud.init()
const db = cloud.database()

exports.main = async (event, context) => {
  const { OPENID } = cloud.getWXContext()
  // OPENID 即为当前用户的唯一标识
  return { openid: OPENID }
}
```

### 4.2 家庭成员数据模型设计

**核心概念**：
- **家庭（Family）**：一个家庭包含多个成员
- **成员（Member）**：关联微信 openid 的家庭成员
- **关系（Relationship）**：成员在家庭中的角色（如"父亲"、"母亲"、"孩子"等）

**推荐数据模型**：

**家庭表（families）**：
```javascript
{
  _id: "family_id",
  name: "我的家庭",
  createTime: Date,
  updateTime: Date,
  inviteCode: "ABC123" // 邀请码，用于成员加入
}
```

**成员表（members）**：
```javascript
{
  _id: "member_id",
  familyId: "family_id", // 关联家庭表
  openid: "user_openid", // 微信用户标识
  nickname: "家庭角色",
  avatar: "头像URL",
  role: "father", // 角色：father/mother/child/etc
  joinTime: Date,
  isAdmin: true // 是否为管理员
}
```

**媒体文件表（media_files）**：
```javascript
{
  _id: "file_id",
  familyId: "family_id", // 关联家庭
  uploaderId: "member_id", // 上传者
  fileID: "cloud://xxx", // 云存储文件ID
  fileType: "image", // image/video
  size: 1024, // 文件大小（字节）
  description: "文件描述",
  createTime: Date
}
```

### 4.3 家庭成员绑定流程

**创建家庭**：
1. 用户首次使用时，创建一个新家庭
2. 用户自动成为家庭管理员
3. 生成邀请码供其他成员加入

**成员加入**：
1. 用户输入邀请码
2. 云函数验证邀请码有效性
3. 将用户 openid 与家庭关联
4. 设置成员角色和权限

**权限控制**：
- 家庭成员只能查看自己家庭的媒体文件
- 通过 `familyId` 进行数据隔离
- 云函数中验证用户是否属于该家庭

**代码示例**（云函数：加入家庭）：
```javascript
exports.main = async (event, context) => {
  const { OPENID } = cloud.getWXContext()
  const { inviteCode } = event

  // 验证邀请码
  const family = await db.collection('families').where({
    inviteCode: inviteCode
  }).get()

  if (!family.data.length) {
    return { success: false, message: '邀请码无效' }
  }

  // 添加成员到家庭
  const result = await db.collection('members').add({
    data: {
      familyId: family.data[0]._id,
      openid: OPENID,
      joinTime: new Date(),
      role: 'member'
    }
  })

  return { success: true, memberId: result._id }
}
```

### 4.4 数据安全与隐私

**安全要点**：
- 所有数据库操作都应通过云函数进行
- 云函数中验证用户权限（检查 openid 是否属于对应家庭）
- 敏感操作（如删除家庭、移除成员）需要管理员权限
- 定期备份数据库

**隐私保护**：
- 不在小程序端直接暴露 openid
- 使用 nickname 而非真实姓名
- 媒体文件访问需要权限验证

## 5. 给非资深开发者的落地建议

### 5.1 技术选择建议

**强烈推荐使用微信云开发**，原因如下：
1. **开箱即用**：无需配置服务器、域名、SSL 证书
2. **深度整合**：与微信授权登录无缝集成，自动获取 openid
3. **成本友好**：免费额度足够个人和小家庭使用
4. **学习成本低**：只需熟悉 JavaScript 即可开始开发

**技术栈建议**：
- **前端**：微信小程序原生开发或 uni-app
- **后端**：微信云开发（云函数 + 云数据库 + 云存储）
- **数据管理**：微信云开发控制台或简单的自定义管理界面

### 5.2 开发步骤建议

**阶段一：基础功能（1-2周）**
1. 创建小程序项目，开通云开发
2. 实现用户登录（自动获取 openid）
3. 创建基础数据表（家庭、成员）
4. 实现媒体文件上传（直传云存储）
5. 实现基础的文件列表展示

**阶段二：核心功能（2-3周）**
1. 实现家庭创建和邀请功能
2. 实现成员管理（添加、移除、角色设置）
3. 实现媒体文件管理（上传、下载、删除）
4. 实现基础的权限控制
5. 添加简单的搜索和分类功能

**阶段三：优化完善（1-2周）**
1. 性能优化（图片压缩、懒加载）
2. 用户体验优化（加载状态、错误提示）
3. 数据备份和恢复
4. 简单的数据统计（存储使用量、成员活跃度）

### 5.3 成本控制建议

**优先使用免费额度**：
- 5GB 存储空间足够初期使用
- 5GB CDN 流量应对小家庭访问绰绰有余
- 数据库操作次数限制（2万读/1万写）充足

**成本优化技巧**：
1. **图片压缩**：上传前对图片进行压缩，减少存储和流量使用
2. **视频限制**：限制视频时长和大小，避免超大文件
3. **定期清理**：实现过期文件自动清理功能
4. **CDN 优化**：使用合适的图片格式和尺寸

**升级时机**：
- 家庭成员超过 10 人
- 月活跃用户超过 50 人
- 存储空间接近免费额度上限
- 需要更复杂的云函数功能

### 5.4 常见问题解决

**上传失败怎么办**：
- 检查网络连接
- 确认云存储权限配置正确
- 查看文件大小是否超过限制
- 使用云函数日志查看详细错误信息

**数据库操作慢**：
- 添加合适的索引
- 避免一次查询过多数据
- 使用分页加载
- 考虑使用云函数进行批量操作

**权限错误**：
- 确保云函数中正确获取 openid
- 检查数据库安全规则配置
- 验证用户是否属于对应家庭

### 5.6 最终建议

**对小程序新手**：
1. **不要过度设计**：从最简单的功能开始，逐步迭代
2. **善用官方工具**：微信开发者工具、云开发控制台功能完善
3. **关注用户体验**：小程序的成功在于简洁和易用
4. **及时备份数据**：定期导出重要数据，避免意外丢失

**对成本敏感**：
- 先使用免费额度，按需升级
- 监控资源使用情况，避免意外超支
- 考虑使用图片压缩、视频转码等优化技术

**对数据安全**：
- 所有敏感操作通过云函数进行
- 定期检查权限配置
- 实现数据备份机制
